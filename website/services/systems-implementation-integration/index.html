What Mellorca avoids

Implementation should not become software accumulation. If configuration, deletion or consolidation solves the problem better than adding another application, that is the stronger result.

Dependencies

Successful delivery may require access to systems, vendor APIs, client subject-matter experts, approved data migration rules and timely decisions on scope. These dependencies should be made explicit before build work begins.

When the target system is not yet clear, architecture should precede implementation.
