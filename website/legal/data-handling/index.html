Data Handling

A plain-language description of how Mellorca treats enquiry data, system access and ownership when we work with you.

Collect only useful context

The contact form is intentionally short. It asks for enough information to understand your enquiry without turning first contact into a procurement questionnaire.

Never send secrets through a form

Please do not submit passwords, API keys, financial credentials, private keys or other system secrets through any form on this website. If a project needs system access, we arrange it separately and securely.

Access follows project need

When a project goes ahead, we request system access deliberately, limit it to the work being performed and ask for it to be removed when it is no longer needed.

Document ownership

Where we build integrations, workflows or automation, we document who owns each part and how it is supported, so nothing depends on memory or on a single person.

How enquiries reach us

Enquiries and briefing sign-ups are delivered securely to Mellorca's own systems, where they are used only for the purposes described in our privacy notice.
